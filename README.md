# Интерактивы: бренд-менеджмент в охране труда

Материалы программы «Бренд-менеджмент в охране труда: как превратить безопасность в культуру, которой гордятся».

## Уроки

- [Урок 1. Бренд в охране труда](index.html) — три ситуации с разбором ответов и карточка задачи для проекта.

## Размещение

Первый интерактив находится в корневом `index.html`. Для следующих уроков можно создавать отдельные папки. Файлы можно встроить в урок по HTTPS после включения GitHub Pages.

Для урока 1: ширина до 688 px с адаптацией под узкий экран; высота 640 px с внутренней прокруткой. Встроен дочерний сценарий iframe-resizer 4.3.11. Если платформа не включает автоматический размер, укажите высоту фрейма 640 px.

Карточка скачивается в TXT. Ответы не отправляются на сервер и исчезают при обновлении страницы. Интеграции с оценками платформы и SCORM нет.

## Права

Авторские материалы программы не распространяются по открытой лицензии. Сторонний iframe-resizer используется по лицензии MIT; текст лицензии находится рядом с интерактивом.
